トリガー一覧

Abs

exprn の絶対値を返します。

戻り値の型は引数の評価結果に従います（整数なら整数、浮動小数点なら浮動小数点）。

  • Abs(exprn)

Acos

Acos は、入力値のアークコサイン（逆余弦）をラジアン(浮動小数点数)で返します。

意味としては Cos(θ) = Exprn を満たす角度 θ を返す関数です（Exprn は「角度」ではなく「余弦値」）。

度に変換したい場合は ExprnResult * 180 / PI を使います。

  • Acos(Exprn)

AILevelは、実行者がAI操作されている場合のAI難易度レベルを整数で返すトリガーです。

  • 返り値: 0（AI操作でない / 人間操作）または 1〜8（AI難易度）
  • AILevel

  • Alive

AnimElem

AnimElem は、現在再生中のアニメーションで「指定した要素（エレメント）」に入った瞬間、または要素開始からの経過フレーム数を比較して真偽（0/1）を返すトリガーです。

  • 書式1: 要素 value1 に入った最初の1フレームのみ真（AnimElem = value1, = 0 と同等）。
  • 書式2: 要素 value1 の開始からの経過フレームを [oper] value2 で比較（実質的に AnimElemTime(value1) [oper] value2 と同等の用途）。

要素番号は0ではなく1から数えます。

  • ; 書式1: 要素 value1 に入った最初の1フレームだけ真（AnimElem = value1, = 0 と同等）
  • AnimElem = value1
  • ; 書式2: 要素 value1 の開始からの経過フレームを [oper] value2 と比較
  • AnimElem = value1, = value2
  • AnimElem = value1, != value2
  • AnimElem = value1, <= value2
  • AnimElem = value1, >= value2
  • AnimElem = value1, > value2
  • AnimElem = value1, < value2
  • ; 例: 要素 value1 の間ずっと真（次の要素が存在する前提）
  • AnimElem = value1, >= 0

AnimElemNo

x経過時間のアニメーションが何枚目かを返します。
特定の経過時間におけるアニメの絵が何枚目かを返します。使用に当たっては、時間の経過をよく考慮する必要があります。
引数には、現時点からの経過時間をintで指定します。例えば、0なら現在、-1なら1フレーム前、1なら1フレーム後です。
注意:ループアニメ部分が表示されている場合、引数にどんな値を指定しても、ループ部分のアニメ順番しか返しません。
  • AnimElemNo(x)

AnimElemTime

アニメーションがx枚目になった時の経過時間を返します。
特定のアニメ順番の経過時間を返します。アニメの順番は0からでなく、1から数えます。
AnimElemトリガーの代わりに登場したトリガーで、ファンクションとして使う場合はこちらを使用します。
引数には、経過時間をチェックしたいアニメ順番をintで指定します。
  • AnimElemTime(x)

  • AnimExist(exprn)

AnimTime

アニメーションが残り何フレームで終了するかを返します。
アニメ終了からの経過時間を返します。アニメが終了していない場合、終了までの時間を負数で返すことになります。
アニメが終了した場合、アニメの最初に戻るか、他のアニメに切り替わることになりますので、基本的にこのトリガーが正の数を返すことはありません。
しかし、最後の絵の表示時間が-1の場合など、「終わらないアニメ」が表示されているときは、表示時間-1の絵になってからの経過時間が、正の数で返されます。
ただし、1枚目の表示時間が-1の場合、1しか返しません。
  • AnimTime

Atan

Atan は、入力値のアークタンジェント（逆正接）をラジアン(浮動小数点数)で返します。

意味としては Tan(θ) = Exprn を満たす角度 θ を返す関数です（Exprn は「角度」ではなく「正接値」）。

Atan は1引数のため、2次元ベクトル（X,Y）から象限込みで角度を求めたい場合は、Exprn = Y / X だけに頼らず、X の符号や X = 0 のケースも含めて条件分岐で補正するのが安全です。

  • Atan(Exprn)

AuthorName

AuthorName は、評価対象キャラクターの .def（[Info] セクション）に記載された author と、指定した文字列を比較し、一致すれば 1、一致しなければ 0 を返します。

本トリガーは「比較式として使うトリガー」であり、単体で値を返す形式ではなく、= / != の比較としてのみ記述できます。

リダイレクト（例: Enemy, AuthorName = "Suika"）と併用して他プレイヤーの作者名を判定できます。リダイレクト先が存在しない場合は bottom になり、式は成立しません。

  • AuthorName = "作者名"
  • AuthorName != "作者名"

BackEdge

BackEdge は、実行者の「背面側」にある画面端（screen edge）の X座標 を、絶対ステージ座標をfloatとして返します。

「背面側」は向き（Facing）に依存します。右向き（Facing = 1）なら背面側は左端、左向き（Facing = -1）なら背面側は右端です。

  • BackEdge

BackEdgeBodyDist

BackEdgeBodyDist は、実行者の背面側（後ろ）の「幅バー端」から、背面側の画面端（screen edge）までの距離を返します。

BackEdgeDist が「実行者のX軸（軸位置）」基準なのに対し、BackEdgeBodyDist は「幅バー端」基準である点が重要です。

返り値はfloatのpx単位の距離。

  • 幅バーの定義: 幅バーはキャラクターの [Size]（例: ground.back/air.back 等）と、Width ステートコントローラによる一時変更の影響を受けます。
  • デバッグ確認: 衝突判定表示（Ctrl+C）でplayer幅（黄色）のバーとして視認できます。
  • BackEdgeBodyDist

BackEdgeDist

「背面側」は向き（Facing）に依存し、右向き時は左端、左向き時は右端が背面側の画面端になります。

返り値はfloatのpx単位の距離です。

HitPauseTime

HitPauseTime は、実行者（P1）の攻撃が相手に接触した際に発生する「ヒットストップ（HitPause）」の残りフレーム数を返します。ヒットストップ中でなければ 0 です。

ヒットストップ開始時の値は、直前に有効だった HitDef の PauseTimeと同じで、以後は毎フレーム 1 ずつ減少します。

ヒットストップ中にこの値を参照したい場合、トリガーを評価するステートコントローラー側で IgnoreHitPause = 1 を指定してください。指定しない場合、ヒットストップ中はコントローラー自体が実行されず、結果として常に 0 になります。

MoveContact

MoveContact は、P1（実行者）の攻撃が相手（P2）に「接触」したかを返します。接触には ヒット と ガード の両方が含まれます。

このトリガーは攻撃ステート（一般に MoveType = A）でのみ有効です。

  • 接触したフレームは 1 を返します。
  • 以後、P1がヒットポーズ等で停止していない更新フレームごとに +1 されます（停止（PauseTime）中は増加しません）。
  • 接触していない場合は 0 を返します。
  • この仕様は、MoveGuarded、MoveHit、MoveReversedで共通です。

MoveContact = 1 は「接触直後」を拾う定番条件です。ただしヒットポーズ中は値が増えないため、ヒットポーズがある場合はその間も = 1 のままになります。

ステート遷移すると Move* 系の接触情報は通常リセットされます。直前ステートの接触情報を次ステートへ持ち越したい場合は、遷移先 StateDef に MoveHitPersist = 1 を指定します。

互換性のため、接触の有無判定は MoveContact（非0）/ !MoveContact（0）で書くのが安全です（MoveContact = 1 固定の比較は意図通りに動かない場合があります）。

  • MoveContact

MoveGuarded

MoveGuarded は、P1（実行者）の攻撃がP2（相手）にガードされた（ガード中、またはガード済み）かを返します。

このトリガーは攻撃ステート（一般に MoveType = A）でのみ意味を持ちます。ガードされていない場合は 0 を返します。

  • ガード接触した更新フレームは 1 を返します。
  • 以後、P1がヒットポーズ等で停止していない更新フレームごとに +1 されます（停止（PauseTime）中は増加しません）。
  • このカウンタ仕様は、MoveContact / MoveHit / MoveReversed と共通です。

MoveGuarded = 1 は「ガード接触直後」を拾う定番条件です。P1が接触で停止している間（例：HitDef の PauseTime による停止）は値が増えないため、その間は = 1 のままになり得ます。

MoveContact / MoveGuarded / MoveHit / MoveReversed は同時にセットされます。例えば、あるHitDefがヒットして MoveHit が非0の最中に、同一の技中で後続のHitDefがガードされると MoveGuarded が非0になり、他の3つは 0 になります。

これらの Move* 値は通常、ステート遷移で 0 にリセットされ増加も止まります。直前ステートの結果を次ステートへ持ち越したい場合は、遷移先 StateDef に MoveHitPersist = 1 を指定します。ステート中に明示的にリセットしたい場合は MoveHitReset を使用します。

互換性のため、判定は MoveGuarded（非0）/ !MoveGuarded（0）で書くのが安全です（MoveGuarded = 1 の固定比較は、停止の影響で想定より長く成立することがあります）。

  • MoveGuarded

MoveHit

MoveHit は、P1（実行者）の攻撃がP2（相手）にヒットしたかを返します（ガードは含みません）。

このトリガーは攻撃ステート（一般に MoveType = A）でのみ有効です。

  • ヒットした更新フレームは 1 を返します。
  • 以後、P1がヒットポーズ等で停止していない更新フレームごとに +1 されます（停止中は増加しません）。
  • ヒットしていない（空振り／ガード）場合は 0 を返します。

MoveHit（非0）/ MoveHit > 0 は「当たった」判定として安全です。MoveHit = 1 は「ヒット直後」を拾う定番条件ですが、ヒットポーズ中は値が増えないため、その間も = 1 のままになりやすい点に注意してください。

MoveContact / MoveGuarded / MoveHit / MoveReversed の値は同時にセットされます。例えば、同一の攻撃中に最初のHitDefがヒットして MoveHit が非0になった後、次のHitDefがガードされると MoveGuarded が非0になり、他の3つは 0 になります。

また、上記4つの Move* トリガーはステート遷移で通常 0 にリセットされます。直前ステートの情報を持ち越したい場合は、遷移先 StateDef に MoveHitPersist = 1 を指定します。任意のタイミングで値を消したい場合はステートコントローラー MoveHitReset を使用します。

ReversalDef によるリバーサル成功の検出にも MoveHit が利用できます。

MoveReversed は、P1（実行者）の攻撃が相手（P2）の ReversalDef によって当て身で返されたかどうかを返します。

このトリガーは攻撃ステート（一般に MoveType = A）でのみ有効です。

上記4種の Move* 系トリガーは「最後に成立した結果」で上書きされます。同一攻撃中に別の結果が成立すると、成立したものだけが非0となり、他は 0 に戻ります。

また、通常はステート遷移で 0 にリセットされます。直前ステートの Move* 系情報を次ステートへ持ち越したい場合は、遷移先 StateDef に MoveHitPersist = 1 を指定します。

姉妹品にHitCountがあり、チームプレイで複数の敵に同時ヒットした場合の扱いが異なります。HitCountの場合は1ヒット、UniqHitCountの場合は2ヒットとして扱われます。
戻り値の型: int
  • UniqHitCount

Var

整数変数（Var）を参照します。Var(N) は整数値を返します。

:=（代入演算子）を使うと、トリガー式の中で Var(N) に値を代入できます。代入式全体の評価結果は「代入された値」です。

無効な変数番号や評価不能な式が入った場合、MUGEN 1.0/1.1 では bottom（評価不能値）になります。条件式では bottom は 0（偽）として扱われるため、エラーは「発火しない」形になります。

  • Var(式)
  • Var(式) := 式

VelX

プレイヤーのX方向の速度を返します。
Vel X は、前方に移動している場合、正の値を返します。(HitVel X の仕様とは逆になります。)
戻り値の型はfloatですが、float型のパラメータをとるステートコントローラでも、floatを返すトリガーをそのまま指定すると、なぜかエラーとなる場合が多いです。floorやceilと併用するようにしましょう。
  • Vel X

VelY

プレイヤーのY方向の速度を返します。
Vel Y は、下方に移動している場合、正の値を返します。
戻り値の型はfloatですが、float型のパラメータをとるステートコントローラでも、floatを返すトリガーをそのまま指定すると、なぜかエラーとなる場合が多いです。floorやceilと併用するようにしましょう。
  • Vel Y

Win

Win は、ラウンドに勝利した場合に 1 を返します（KO・時間切れ・その他の勝利条件を含む／チーム戦ではチーム単位）。

勝利条件の内訳が必要な場合は WinKO / WinTime / WinPerfect を併用します。

勝敗確定のフレーム帯は通常 RoundState = 3（ラウンド終了処理）以降です。ラウンド勝利直後の処理は RoundState と組み合わせて行うのが安全です。

  • Win

WinKO

WinKO は、ラウンドを「KO（相手の Life が 0 になって決着）」で勝利した場合に 1 を返します（チーム戦ではチーム単位）。

勝敗確定のフレーム帯は通常 RoundState = 3（ラウンド終了処理）以降です。ラウンド勝利直後の処理は RoundState と組み合わせて行うのが安全です。

  • WinKO

WinPerfect

WinPerfect は、ラウンドを「無傷（no life lost）」で勝利した場合に 1 を返します（チーム戦ではチーム単位）。

勝敗確定のフレーム帯は通常 RoundState = 3 以降です。パーフェクト専用の演出分岐は RoundState と組み合わせて行うのが安全です。

  • WinPerfect

WinTime

WinTime は、ラウンドを「時間切れ（Time Over）」で勝利した場合に 1 を返します（チーム戦ではチーム単位）。

時間切れで引き分けの場合は DrawGame が 1 になり、WinTime は 0 のままです。

勝敗確定のフレーム帯は通常 RoundState = 3 以降です。時間切れ勝利直後の処理は RoundState と組み合わせて行うのが安全です。

  • WinTime
