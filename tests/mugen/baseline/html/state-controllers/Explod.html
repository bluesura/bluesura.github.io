Type = Explod

演出 > 独立したアニメーション(Explod)の表示 | 実装されたバージョン: 2002.04.14 | 対象: 画像

指定した番号のアニメーションをAIRファイルから呼び出して表示します。

同時に存在できる総数には上限があり、標準では64個(Mugen1.0から256個)となっています。仮にプレイヤー1(P1)が64個出してしまった場合、プレイヤー2(2P)は1つも出せなくなります。総数の上限はmugen.cfgのExplodMaxで変更できます。大きい値にするほど、PCへの負荷が大きくなります。動作が重かったりする場合は、この値を下げることにより改善する場合があります。

関連するステートコントローラー： RemoveExplod , ModifyExplod , ExplodBindTime
関連するトリガー： NumExplod , PlayerIDExist

パラメーター

Explodに割り当てるIDを指定します。

省略時のデフォルト値： 0
Facing = 向き (整数)

スプライトの向きを指定。1で正、-1で負の方向を向きます。

省略時のデフォルト値： 1
VFacing = 上下の向き (整数)

-1にすると、垂直方向に反転表示されます。

省略時のデフォルト値： 1
Pos = x座標, y座標 (整数, 整数)

スプライトの初期出現位置を指定します。

最小値: -2147483647, -2147483647 , 最大値: 2147483647, 2147483647

PosType = 基準点の位置 (文字列)

アニメーションを出現させるための基準点(0,0)をどこにするか、以下の文字列から指定します。

タイプ 基準
P1

実行者が基準点(0,0)になります。X軸の正数は実行者の正面・Y軸の負数は実行者の頭上。
P2

実行者に最も近い敵が基準点(0,0)になります。X軸の正数は最も近い敵の正面・Y軸の負数は最も近い敵の頭上。
F

FはFrontの略。実行者の正面の画面端が基準点(0,0)になります。X軸の負数は基準点から実行者の方向・Y軸の負数は地面から上。
B

BはBackの略。実行者の背面の画面端が基準点(0,0)になります。X軸の正数は基準点から実行者の方向・Y軸の負数は地面から上。
L

LはLeftの略。画面左上が基準点(0,0)になります。X軸の正数は画面右方向・Y軸の正数は画面下方向。
R

RはRightの略。画面右上が基準点(0,0)になります。X軸の負数は画面左方向・Y軸の正数は画面下方向。
N

NはNoneの略。ステージ中央が基準点(0,0)になります。他のPosTypeと違い基準点は絶対に動きません。X軸は右方向が正数・左方向が負数。Y軸は上方向が負数・下方向が正数。

Version1.1から追加された値です。
省略時のデフォルト値： P1 ;Version1.1からはNoneに変更されています。
Space = 座標の方法 (文字列)

アニメーションを表示する座標をどのようにするかを指定します。

Version1.1から利用可能なパラメーター。PosTypeの代替パラメーターで、優先してSpaceが読み込まれます。

タイプ 基準
Screen 座標は画面に依存。画面左上が(0,0)、右下が(ScreenWidth,ScreenHeight)になります。カメラの動きやズームの影響を受けません。
Stage 座標はステージに依存。座標(0,0)は(ステージの中央,ステージで設定した地面)になります。カメラの動きとズームの影響を受けます。
省略時のデフォルト値： Stage

BindID = bind_id (整数)
拘束元のプレイヤーＩＤを指定, デフォルトは-2, -1なら任意・-2なら拘束しない, ヘルパーからExplodを出した場合、HelperTypeがPlayerでないと無効

ID number of a player or helper to bind to. The position of a bound explod is relative to the object that it is bound to. Special values are -1 (bind to any single player) and -2 (do not bind). IgnoreHitPause = ヒット停止中も処理するか (0か1)

HitPauseTime（ヒット停止）中に、このステートコントローラーを評価・実行するかを指定します。

  • 0（既定）: ヒット停止中は評価されません。
  • 1: ヒット停止中も評価・実行されます。

値は0/1の整数定数のみです（var等の式は使用不可）。

注意: ヒット停止中はIgnoreHitPause=1のステコンだけが実行・内部制限カウントの対象になる挙動が報告されており、通常制作では問題になりませんが、極端な条件下では想定外の挙動が起きる可能性があります。

補足: [StateDef -3]は投げ等で他者のステートデータを使用している間はチェックされないため、IgnoreHitPauseを1にしても走らない局面があります。

IKEMEN GO: ZSSの後方互換性対応や挙動整合のため、IgnoreHitPause周辺はリリース間で修正・拡張が入っています。MUGENと完全一致しないケースもあり得るため、互換性重視のコードは対象ビルドで挙動確認してください。

最小値: 0 , 最大値: 1
省略時のデフォルト値： 0
Persistent = 実行頻度（トリガー成立回数の間引き） (整数)

Persistent は、このステートコントローラーが「実行可能（発火）」になった回数を基準に、実行頻度を間引くための共通パラメーターです。

まず「トリガー成立（= 実行可能）」の定義は次のとおりです。

  • triggerall は共通の前提条件（AND）です。triggerall が偽のフレームでは、trigger1 以降が成立していても発火しません。
  • trigger1 / trigger2 / trigger3 ... は番号ごとにグループで評価されます。
    • 同じ番号（例：trigger1 が複数行）は AND（全部真ならその番号グループが真）。
    • 番号が違うグループ同士（trigger1 と trigger2 など）は OR（どれか1つのグループが真なら発火）。

この「発火（トリガー成立）」が起きた回数に対して、Persistent は次のように動作します。

  • 1（既定）: 発火するたびに毎回実行します。
  • 0: そのステートにいる間は最初の1回だけ実行します（ステートを離れて戻るとカウントはリセットされ、再び1回実行可能になります）。
  • N（2以上）: 発火したN回に1回だけ実行します。
    例：発火が毎フレーム続く（= 毎フレーム発火条件が真）なら、見かけ上はNフレームに1回の実行になります。発火が断続的な場合は、実行間隔も断続的になります（“フレーム”ではなく“発火回数”で数えるため）。

値に指定できるのは整数定数のみです（var/fvar/sysvar を含む式は不可）。

注意: 一部の解析記事では、エンジン内部でステート内のステートコントローラーごとに「Persistent用のカウンタ」が確保され、最大512個相当まで管理される、と説明されています。極端に大量のステートコントローラーを1つのステートに詰め込む設計は、可読性だけでなく実装上の制約にも触れやすいため、常時処理が肥大化している場合は分割・整理を推奨します。

最小値: 0 , 最大値: 128
省略時のデフォルト値： 1

仕様・バグ・エラー・変更点

-BindTime=0でPosTypeを指定していてもPosType=Leftとして扱われるようになってしまうため、スプライトが画面外に消える・消えなくてもおかしな位置に表示される可能性がある。
-未検証：ScreenBoundで画面を固定していると、Explodが本体に追従できずに数Fの間ずれることがある。
-未検証：AfterImage系統と異なり、ModifyExplodを用いてもRemoveTimeで消えるまでの残り時間は変わらない。
-未検証：IgnoreHitPause=1ではHitPauseTime中にも出る、またAnimが動作する。IgnoreHitPauseを省略するとHitPauseTime中には出ない、またAnimeが動く。IgnoreHitPause=0ではHitPauseTime中には出ない、またAnimが動かない。
Version1.0より前Explodを消去する前に、Explodを管理しているHelperをDestroySelfで消去してしまうとExplodが残り続けます。
Version1.1からExplodのPosTypeがP1とP2以外の時に、EnvShake（画面振動）の影響を受けなくなった
Version1.1から-2に記述されたExplodはステートが奪われた場合、奪った相手のLocalCoordの影響を受け縮尺がおかしくなります。
Version1.1からSpace,Angle,XAngle,YAngle,ReMapPal,BindID,PosTypeにNoneが追加されました。
Version1.1からSuperMoveが廃止されました。

コードサンプル

SpaceでPosTypeを再現する方法

  • ;PosType = P1
  • Space = Stage
  • Pos = Pos X + CameraPos X, Pos Y
  • Facing = Facing
  • ;PosType = P2
  • Space = Stage
  • Pos = (EnemyNear, Pos X) + CameraPos X, (EnemyNear, Pos Y)
  • Facing = EnemyNear, Facing
  • ;PosType = Front
  • Space = Screen
  • Pos = IfElse(Facing = -1, 0, ScreenWidth), 0
  • Facing = 1
  • ;PosType = Back
  • Space = Screen
  • Pos = IfElse(Facing = 1, 0, ScreenWidth), 0
  • Facing = Facing
  • ;PosType = Left
  • Space = Screen
  • Pos = 0, 0
  • Facing = 1
  • ;PosType = Right
  • Space = Screen
  • Pos = ScreenWidth, 0
  • Facing = 1
