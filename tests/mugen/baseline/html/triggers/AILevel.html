AILevel

AI > AI難易度レベルの取得 | 実装されたバージョン: MUGEN 1.0 RC2 | 対象: 実行者

AILevelは、実行者がAI操作されている場合のAI難易度レベルを整数で返すトリガーです。

  • 返り値: 0（AI操作でない / 人間操作）または 1〜8（AI難易度）
関連するトリガー： Command , IsHelper

構文

  • AILevel

引数

なし

仕様・バグ・エラー・変更点

MUGEN 1.0 RC2 (2009-09-29)

追加: CNSの新トリガーとしてAILevelが追加され、AI難易度設定を返せるようになりました。

MUGEN 1.0 RC4 (2009-10-25)

修正: トレーニングモードの「cooperative dummy」周りで、AILevelが誤動作するケースが修正されています。

IKEMEN (legacy)

修正履歴: HelperにおけるAILevelの修正履歴があり、派生実装ではHelper/Rootで値が食い違う可能性があります。

Q＆A(よくある質問)

対戦中にAIのON/OFFを切り替える方法は？

デバッグキーとしてCtrl+#（1から4の数字キー）で「#番目のプレイヤーのAI」をトグルできます。

AILevelはどこで設定する？

通常は、起動画面の Option → Difficulty（COM難易度）で設定します。

Trainingでは、ダミー操作がAIのときに Training menu → AI level で調整できます。

コードサンプル

AI判定＋敵AIレベル表示

AILevelは自分側と相手側で別々に評価できます。

  • [State -2, AIレベルの確認]
  • Type = DisplayToClipboard
  • Trigger1 = 1
  • Text = "P1 AILevel:%d / P2 AILevel:%d"
  • Params = AILevel, EnemyNear,AILevel

AI専用分岐の最小例

AILevel > 0を「AI操作中」の簡易判定として扱い、変数に保持しておく例です。

  • [State -2, AIFlag]
  • Type = VarSet
  • Trigger1 = 1
  • Var(59) = (AILevel > 0)
  • IgnoreHitPause = 1
