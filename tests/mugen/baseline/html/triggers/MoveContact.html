MoveContact

ヒット情報 > 攻撃の接触判定 | 実装されたバージョン: 2002.04.14 | 対象: 実行者自身

MoveContact は、P1（実行者）の攻撃が相手（P2）に「接触」したかを返します。接触には ヒット と ガード の両方が含まれます。

このトリガーは攻撃ステート（一般に MoveType = A）でのみ有効です。

  • 接触したフレームは 1 を返します。
  • 以後、P1がヒットポーズ等で停止していない更新フレームごとに +1 されます（停止（PauseTime）中は増加しません）。
  • 接触していない場合は 0 を返します。
  • この仕様は、MoveGuarded、MoveHit、MoveReversedで共通です。

MoveContact = 1 は「接触直後」を拾う定番条件です。ただしヒットポーズ中は値が増えないため、ヒットポーズがある場合はその間も = 1 のままになります。

ステート遷移すると Move* 系の接触情報は通常リセットされます。直前ステートの接触情報を次ステートへ持ち越したい場合は、遷移先 StateDef に MoveHitPersist = 1 を指定します。

互換性のため、接触の有無判定は MoveContact（非0）/ !MoveContact（0）で書くのが安全です（MoveContact = 1 固定の比較は意図通りに動かない場合があります）。

関連するステートコントローラー： HitDef
関連するトリガー： MoveHit , MoveGuarded , MoveReversed

構文

  • MoveContact

引数

なし

仕様・バグ・エラー・変更点

Dos版

戻り値の型がboolean int (1 or 0)。

Win版

戻り値の型がint。

MUGEN 1.0 / 1.1

接触時に 1、以後はP1が停止していないフレームごとに増加するカウンタを返します（停止中は増加しません）。

この「停止中は増えない」性質により、MoveContact = 1 はヒットポーズ中も成立しやすい点に注意してください。

コードサンプル

攻撃が空振りしていなければ発動（ヒット/ガード問わず）

  • Trigger1 = MoveContact

接触直後（値が1の間）を拾う

MoveContact = 1 は「接触した瞬間」を拾う用途でよく使われます。ヒットポーズ中は値が増えないため、ヒットポーズがある場合はその間も = 1 のままになります。

  • Trigger1 = MoveContact = 1
