E

定数 > 自然対数の底 | 実装されたバージョン: 2002.04.14
引数 使用例 引用記事

E は自然対数の底 e（ネイピア数）を返す定数です。

戻り値の型: float

E 単体は定数ですが、E ** x で「e を底にしたべき乗」を作れます。指数関数を直接求めたい場合は Exp(x) を使います。

関連するトリガー： Exp , Ln , Log

構文

  • E

引数

なし

Eを底にした指数減衰（毎フレーム一定割合で減る）

毎フレーム 係数 = E ** (-k) を掛けると、値は指数的に0へ近づきます（減衰）。

下のアニメーションは「指数減衰（e^{-kt}）」と「線形減少」の違いを同じ初期値で比較します。

  • [State -2, 減衰率を事前計算]
  • Type = VarSet
  • Trigger1 = !Time
  • FV = 10
  • Value = E ** (-0.10) ; 1フレームあたり約0.9048倍
  • [State -2, 速度を指数減衰させる]
  • Type = VelMul
  • Trigger1 = 1
  • X = FVar(10)
  • Y = FVar(10)

自然対数との関係（Ln と Log(E, x)）

自然対数（底が E の対数）は、Ln(x) と Log(E, x) のどちらでも表せます。

  • [State -2, xを用意]
  • Type = VarSet
  • Trigger1 = !Time
  • FV = 0
  • Value = 10.0
  • [State -2, Ln(x)]
  • Type = VarSet
  • Trigger1 = !Time
  • FV = 1
  • Value = Ln(FVar(0))
  • [State -2, Log(E, x)]
  • Type = VarSet
  • Trigger1 = !Time
  • FV = 2
  • Value = Log(E, FVar(0))
  • [State -2, 表示]
  • Type = DisplayToClipboard
  • Trigger1 = 1
  • Text = "x=%f | Ln(x)=%f | Log(E,x)=%f"
  • Params = FVar(0), FVar(1), FVar(2)
