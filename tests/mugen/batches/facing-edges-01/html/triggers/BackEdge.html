BackEdge

座標 > 背面側画面端（screen edge）のX座標（ステージ座標系） | 実装されたバージョン: 1.1 | 対象: 実行者自身
引数 仕様・注意点 使用例 引用記事

BackEdge は、実行者の「背面側」にある画面端（screen edge）の X座標 を、絶対ステージ座標をfloatとして返します。

「背面側」は向き（Facing）に依存します。右向き（Facing = 1）なら背面側は左端、左向き（Facing = -1）なら背面側は右端です。

関連するステートコントローラー： ScreenBound

Q＆A(よくある質問)

BackEdgeDist / BackEdgeBodyDist と何が違いますか？

BackEdge は背面側画面端の X座標（絶対ステージ座標）を返します。

BackEdgeDist は実行者のX軸（axis）から背面側画面端までの 距離、BackEdgeBodyDist は幅バー端から背面側画面端までの 距離 を返します。

「画面外に出たか」「画面端が何pxにあるか」を扱うなら BackEdge、「あと何pxで画面端か」を扱うなら BackEdgeDist/BackEdgeBodyDist が向いています。

「画面端」はステージ端と同じですか？

同一ではありません。FrontEdge が参照するのは現在のカメラ表示範囲の端（screen edge）です。カメラ追従やズーム、ScreenBound 等の制御により、画面端の座標は状況で変化します。

Ikemen GO でも同じように使えますか？

Ikemen GO は「M.U.G.E.N 1.1 Beta 相当の互換性」を目標にしているため、基本的には同系の記述を前提にできます。

ただし互換エンジンはバージョン（Nightly/Release）や独自拡張によって差が出ることがあるため、最終的には対象ビルドでの実機確認を推奨します。

コードサンプル

公式例：背面側画面端より外（背面側）に出たか判定する

絶対ステージ座標系で比較し、実行者が背面側画面端より外側に出た状況を拾う例です。

  • Trigger1 = Pos X + CameraPos X < BackEdge

向き（Facing）に依存せず、背面側へ画面外に出たかを1式で判定する

右向き/左向きで不等号の向きが変わる問題を、Facing の符号で吸収します。

  • Trigger1 = Facing * (Pos X + CameraPos X) < Facing * BackEdge
