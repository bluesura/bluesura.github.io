HitPauseTime

時間 > ヒットストップの残り時間取得 | 実装されたバージョン: 2002.04.14 | 対象: 実行者自身
引数 仕様・注意点 使用例 引用記事

HitPauseTime は、実行者（P1）の攻撃が相手に接触した際に発生する「ヒットストップ（HitPause）」の残りフレーム数を返します。ヒットストップ中でなければ 0 です。

ヒットストップ開始時の値は、直前に有効だった HitDef の PauseTimeと同じで、以後は毎フレーム 1 ずつ減少します。

ヒットストップ中にこの値を参照したい場合、トリガーを評価するステートコントローラー側で IgnoreHitPause = 1 を指定してください。指定しない場合、ヒットストップ中はコントローラー自体が実行されず、結果として常に 0 になります。

リダイレクトを使えば、Enemy,HitPauseTime のように相手側の値も参照できます。

関連するステートコントローラー： HitDef
関連するトリガー： HitPauseTime

構文

  • HitPauseTime
  • Enemy, HitPauseTime

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.0

    2002.04.14 系から 1.0 へ更新する際、HitDef の PauseTime は挙動修正のため「P1 側（1つ目）」に +1 が必要です。古いキャラを移植すると、HitPauseTime の初期値が 1 フレームずれる原因になります。

  • Ikemen GO

    互換仕様の基本は MUGEN 1.1 の公式ドキュメント参照が前提。HitPauseTime は変更トリガー一覧に含まれないため、基本挙動は MUGEN 1.1 相当として扱えます。

Q＆A(よくある質問)

HitPauseTime が常に 0 になる

HitPauseTime は「ヒットストップ中の残りフレーム」を返しますが、ヒットストップ中は通常ステートコントローラーが実行されません。

そのため、ヒットストップ中に参照したいステートコントローラーへ IgnoreHitPause = 1 を付けてください。

コードサンプル

ヒットストップ中でない判定

0 ならヒットストップ中ではありません。

  • Trigger1 = HitPauseTime = 0

ヒットストップ中にだけフラグを立てる（IgnoreHitPause）

ヒットストップ中に評価したい側のコントローラーへ IgnoreHitPause = 1 を付けます。

  • [State -2, HitStopFlagOn]
  • Type = VarSet
  • Trigger1 = HitPauseTime > 0
  • IgnoreHitPause = 1
  • V = 20
  • Value = 1
  • [State -2, HitStopFlagOff]
  • Type = VarSet
  • Trigger1 = HitPauseTime = 0
  • V = 20
  • Value = 0
