PI

数値計算 > 円周率(PI) | 実装されたバージョン: 2002.04.14 | 対象: 数式
引数 使用例 引用記事

PI は円周率π（3.141593...）の近似値を返すトリガーです。

戻り値は浮動小数点数で、数式内でそのまま利用できます。

関連するトリガー： Sin , Cos , Tan , Acos , Asin , Atan

構文

  • PI

引数

なし

Q＆A(よくある質問)

ラジアンと度の変換はどう書く？

度にしたい場合は ラジアン * 180 / PI、ラジアンに戻したい場合は 度 * PI / 180 を使います。

コードサンプル

速度ベクトルから角度（度）を求める

Atan() の戻り（ラジアン）を 180 / PI で度に変換します。分母が 0 になりうる場合は IfElse などで回避してください。

  • [State 0, AngleFromVel]
  • Type = AngleSet
  • Trigger1 = 1
  • Value = IfElse(Vel X != 0, -180.0 / PI * Atan(Vel Y / Vel X), IfElse(Vel Y < 0, 90.0, -90.0))

Sin波でExplodのスケールを揺らす

2 * PI を使って周期（ここでは32フレーム）を作り、Sin() でスケールを揺らします。

  • [State -2, ExplodScaleWave]
  • Type = ModifyExplod
  • TriggerAll = NumExplod(8865)
  • Trigger1 = Root, StateNo = 3703
  • Scale = FVar(32) ** 0.5 * 0.7 , FVar(32) * (1.0 + 0.3 * Sin(PI * 2.0 / 32.0 * (Time % 32 + Random % 8)))
  • Trans = AddAlpha
  • Alpha = 100, 255
  • ID = 8865
  • IgnoreHitPause = 1

角度（ラジアン）を -PI〜PI に正規化する

角度を -PI〜PI の範囲に保つ例です（1周 = 2 * PI）。

  • [State 0, WrapAngleRad]
  • Type = VarAdd
  • Trigger1 = FVar(4) >= PI || FVar(4) <= -PI
  • FVar = 4
  • Value = IfElse(FVar(4) >= PI, -2.0 * PI, 2.0 * PI)

狙い角度にランダムなブレを加える

相対位置から角度を作り、Random で微小なブレ（度）を加えます。

  • [State -3, AimAngleDeg]
  • Type = VarSet
  • Trigger1 = Var(0) = [0,1]
  • Var = 3
  • Value = IfElse((P2BodyDist X + 50) != 0, Atan((-1.0 * (P2BodyDist Y - 50)) / (P2BodyDist X + 50)) * 180.0 / PI, 0.0) + (IfElse(Random % 2 = 0, -1, 1) * (Random % 10))

角度の許容範囲（±25度）で条件分岐する

相手との相対位置から角度（度）を求め、範囲内かどうかで処理を分ける例です。

  • [State -1, AngleGate]
  • Type = VarSet
  • TriggerAll = Var(20) = 1
  • TriggerAll = StateNo = 640
  • Trigger1 = (P2Dist X - 39) > 0
  • Trigger1 = Atan((P2Dist Y + 53 + EnemyNear, Const(Size.Mid.Pos.Y)) / (P2Dist X - 39)) * 180.0 / PI <= 25
  • Trigger2 = (P2Dist X - 39) < 0
  • Trigger2 = Atan((P2Dist Y + 53 + EnemyNear, Const(Size.Mid.Pos.Y)) / (P2Dist X - 39)) * 180.0 / PI >= -25
  • FVar = 0
  • Value = 25
