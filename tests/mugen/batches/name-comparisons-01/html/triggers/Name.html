Name

キャラクター情報 > キャラクター名（Def:Name）の判定 | 実装されたバージョン: 2002.04.14 | 対象: 評価対象（既定: 実行者自身）
引数 使用例 引用記事

Name は、評価対象キャラクターの .def（[Info] セクション）に記載された内部名 name と、指定した文字列を比較し、一致すれば 1、一致しなければ 0 を返します。

本トリガーは「比較式として使うトリガー」であり、単体で値を返す形式ではなく、= / != の比較としてのみ記述できます。

内部名は、画面表示名（ライフバー等で表示される名称）と必ずしも一致しません。リダイレクト（例: Enemy, Name = "Kumquat"）と併用して他プレイヤーの内部名も判定できます。リダイレクト先が存在しない場合は bottom になり、式は成立しません。

関連するトリガー： AuthorName , P1Name , P2Name , P3Name , P4Name

構文

  • Name = "名前"
  • Name != "名前"

引数

なし

コードサンプル

自キャラクターの内部名で分岐する

内部名が一致した場合のみ処理を通します。

  • [State -2, NameGate]
  • Type = AssertSpecial
  • Trigger1 = Name = "Kumquat"
  • Flag = NoAutoTurn
