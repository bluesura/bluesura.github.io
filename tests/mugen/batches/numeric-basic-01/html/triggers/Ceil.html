Ceil

数値計算 > 小数点以下の切り上げ | 実装されたバージョン: 2002.04.14
引数 仕様・注意点 使用例 引用記事

天井関数（Ceil）です。引数以上の最小の整数を返します。

負数のときも数学的な Ceil として動作します（例: Ceil(-2.3) = -2）。

関連するトリガー： Floor

構文

  • Ceil(exprn)

引数

exprn

省略不可
型浮動小数点数

Ceilを計算する式を指定します（整数も指定可能）。

仕様・バグ・エラー・変更点

  • 2002.04.14系（旧ドキュメント表記）

    exprn が SFalse の場合は SFalse を返します。

  • MUGEN 1.0/1.1

    exprn が bottom の場合は bottom を返します。

コードサンプル

小数を整数へ（正数）

  • ; 6
  • value = Ceil(5.5)

小数を整数へ（負数）

負数はより大きい整数側へ丸められます。

  • ; -2
  • value = Ceil(-2.3)
