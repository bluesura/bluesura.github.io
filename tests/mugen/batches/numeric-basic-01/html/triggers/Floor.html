Floor

数値計算 > 小数点以下の切り捨て | 実装されたバージョン: 2002.04.14
引数 仕様・注意点 使用例 引用記事

床関数（Floor）です。引数以下の最大の整数を返します。

負数のときも「0方向への丸め」ではなく、数学的な Floor として動作します（例: Floor(-2.3) = -3）。

関連するトリガー： Ceil

構文

  • Floor(exprn)

引数

exprn

省略不可
型浮動小数点数

Floorを計算する式を指定します（整数も指定可能）。

仕様・バグ・エラー・変更点

  • 2002.04.14系（旧ドキュメント表記）

    exprn が SFalse の場合は SFalse を返します。

  • MUGEN 1.0/1.1

    exprn が bottom の場合は bottom を返します。

コードサンプル

小数を整数へ（正数）

  • ; 5
  • value = Floor(5.5)

小数を整数へ（負数）

負数はより小さい整数側へ丸められます。

  • ; -3
  • value = Floor(-2.3)
