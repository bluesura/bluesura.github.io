NumPartner

試合情報 > パートナー数の取得 | 実装されたバージョン: 2002.04.14 | 対象: 味方
引数 使用例 引用記事
現在のパートナー数を返します。
実行者のパートナーの数を返します。シングルは0、タッグは1、チーム戦は1です。ヘルパーはパートナーとしてカウントされません。
改造でパートナーの数を増やした場合でも正しいパートナーの数を返してきます。
戻り値の型: int

構文

  • NumPartner

引数

なし

コードサンプル

プレイヤー番号をvar(1)に代入

  • [State , タッグ戦の場合]
  • Type = Null
  • ;シングル戦だったときのWARNINGメッセージ回避策
  • TriggerAll = NumPartner
  • ;プレイヤー1
  • Trigger1 = TeamSide = 1 && ID > partner,ID
  • Trigger1 = var(1) := 1
  • ;プレイヤー2
  • Trigger2 = TeamSide = 2 && ID > partner,ID
  • Trigger2 = var(1) := 2
  • ;プレイヤー3
  • Trigger3 = TeamSide = 1 && ID < partner,ID
  • Trigger3 = var(1) := 3
  • ;プレイヤー4
  • Trigger4 = TeamSide = 2 && ID < partner,ID
  • Trigger4 = var(1) := 4
  • ;不明
  • Trigger5 = var(1) := -1
  • [State , シングル・チーム戦の場合]
  • Type = Null
  • ;タッグ戦だった場合に読み込まれないようにするため
  • TriggerAll = !NumPartner
  • ;プレイヤー1
  • Trigger1 = TeamSide = 1
  • Trigger1 = var(1) := 1
  • ;プレイヤー2
  • Trigger2 = TeamSide = 2
  • Trigger2 = var(1) := 2
  • ;不明
  • Trigger3 = var(1) := -1

プレイヤーのパートナーが1人で、そのパートナーの体力が200未満の場合のトリガー

  • [State ]
  • Type = Null
  • Trigger1 = NumPartner = 1
  • Trigger1 = Partner,Life < 200
