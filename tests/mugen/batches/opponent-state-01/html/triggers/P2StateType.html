P2StateType

ステータス > 現在ステートタイプの判定 | 実装されたバージョン: 2002.04.14
引数 使用例 引用記事
P2のStateTypeを判定し、真偽を返します。
ゲームクリア、ゲームオーバー画面など、P2が存在しない場合は0を返します。
関連するステートコントローラー： S , C , A , U , StateTypeSet
関連するトリガー： StateType

構文

  • P2StateType = S
  • P2StateType = C
  • P2StateType = A
  • P2StateType = L
  • P2StateType != S
  • P2StateType != C
  • P2StateType != A
  • P2StateType != L

引数

なし

コードサンプル

分身バグ対策

ヘルパーがキャラに分身することを防ぎます。[StateDef 0]内に記述して下さい。
  • [State 0]
  • Type = DestroySelf
  • Trigger1 = IsHelper
