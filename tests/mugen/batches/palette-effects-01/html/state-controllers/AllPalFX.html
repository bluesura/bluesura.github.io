Type = AllPalFX

色の操作 > 画面全体のカラーパレット変更 | 実装されたバージョン: 2002.04.14 | 対象: 画面
パラメーター 仕様・注意点 コピペ用 使用例 読み込み順 引用記事

画面全体のパレットに指定色を加算・乗算します。

OwnPalパラメーターを無視して、画面,ステージ,ライフバー,キャラクター(Explod,Helperを含む)などのオブジェクトに適用されます。ただし、AllPalFXは影響を受けない,PalFX系で上書き,SuperPauseによる暗転を行うと背景や相手への効果が消える,AfterImageの残像,ライフバーのアニメーション,キャラクターの影など例外があります。

キャラクターのみに加算する場合はPalFX,背景のみに加算する場合はBGPalFX,指定色で塗りつぶしたい場合はEnvColor。

関連するステートコントローラー： PalFX , BGPalFX , EnvColor

Time = 持続時間

型整数
省略時0
最小値-1
最大値2147483647

効果の持続時間をフレーム単位で指定します。

-1で表示を永続化。0では表示されず、1以上か-1を指定しなければなりません。

ステートが変わっても有効のため、効果持続中にやられステートへ移行しても効果は持続します。回避方法は、AllPalFXをTime=1に設定してトリガーで時間を調整します。ただし、SinAddが機能しないので注意。別の方法は、効果を終わらせたいタイミングでTime=0だけを指定したAllPalFXを実行して値を上書きします。ただし、相手プレイヤーのAllPalFXを打ち消すことがあるので管理に注意。

※60フレーム=1秒

Color = 彩度

型整数
省略時256
最小値0 ;グレースケール
最大値256 ;変化なし

パレットの彩度を下げます。

例: 彩度を低くした時、明るい色ほど白・暗い色ほど黒に近づきます。
　
　　　　
　　　　　　　　
　　　　　　　　　　　
　　　　　　　　
　　　　
　
0←　　　　　　　　→256

Add = 加算する赤色, 加算する緑色, 加算する青色

型整数, 整数, 整数
省略時0, 0, 0
最小値-256, -256, -256 ;黒
最大値256, 256, 256 ;白

指定した色をパレットに加算します。

暗い色ほど指定色に近づき、色の合計値が大きくなるほど、色が明るくなります。

例: 　Add=256,0,0の場合、　黒(0,0,0)は　赤(256,0,0)になりますが、　白(256,256,256)は　白(256,256,256)のままです。

Mul = 合成する赤色, 合成する緑色, 合成する青色

型整数, 整数, 整数
省略時256, 256, 256
最小値1, 1, 1
最大値256, 256, 256 ;変化なし

基本色(パレット+Add+SinAddの合計値)に合成色(Mulで指定した値)/256を乗算します。

合成色の値が小さくなるほど、色が暗くなります。明るい色ほど合成色に近づきます。

例: 　Add=64,256,64,Mul=1,256,1の場合、　白(256,256,256)は　緑(1,256,1)になりますが、　黒(0,0,0)は　黒(0,0,0)のままです。

SinAdd = 周期する赤色, 周期する緑色, 周期する青色, 周期

型整数, 整数, 整数, 整数
省略時0, 0, 0, 0

指定色を、指定周期(単位はフレーム)の正弦波でパレットに加算/減算。

周期が大きいほどゆるやかに色が変化します。

例: 　SinAdd=0,0,256,20,　Add=0,0,0,Mul=256,256,256の場合、　(128,128,128)は、5F後　(128,128,256)になり、10F後　(128,128,128)に戻り、15F後　(128,128,0)、20F後　(128,128,128)に戻る、という周期を繰り返します。

InvertAll = 色反転フラグ

型0か1
省略時0
最小値0 ;色が反転しない
最大値1 ;色が反転する

色を反転するか・しないかのフラグです。

例: 　(0,0,0)→　(256,256,256),　(0,252,0)→　(256,4,256),　(256,0,0)→　(0,256,256)

IgnoreHitPause = ヒット停止中も処理するか

型0か1
省略時0
最小値0
最大値1

HitPauseTime（ヒット停止）中に、このステートコントローラーを評価・実行するかを指定します。

  • 0（既定）: ヒット停止中は評価されません。
  • 1: ヒット停止中も評価・実行されます。

値は0/1の整数定数のみです（var等の式は使用不可）。

注意: ヒット停止中はIgnoreHitPause=1のステコンだけが実行・内部制限カウントの対象になる挙動が報告されており、通常制作では問題になりませんが、極端な条件下では想定外の挙動が起きる可能性があります。

補足: [StateDef -3]は投げ等で他者のステートデータを使用している間はチェックされないため、IgnoreHitPauseを1にしても走らない局面があります。

IKEMEN GO: ZSSの後方互換性対応や挙動整合のため、IgnoreHitPause周辺はリリース間で修正・拡張が入っています。MUGENと完全一致しないケースもあり得るため、互換性重視のコードは対象ビルドで挙動確認してください。

Persistent = 実行頻度（トリガー成立回数の間引き）

型整数
省略時1
最小値0
最大値128

Persistent は、このステートコントローラーが「実行可能（発火）」になった回数を基準に、実行頻度を間引くための共通パラメーターです。

まず「トリガー成立（= 実行可能）」の定義は次のとおりです。

  • triggerall は共通の前提条件（AND）です。triggerall が偽のフレームでは、trigger1 以降が成立していても発火しません。
  • trigger1 / trigger2 / trigger3 ... は番号ごとにグループで評価されます。
    • 同じ番号（例：trigger1 が複数行）は AND（全部真ならその番号グループが真）。
    • 番号が違うグループ同士（trigger1 と trigger2 など）は OR（どれか1つのグループが真なら発火）。

この「発火（トリガー成立）」が起きた回数に対して、Persistent は次のように動作します。

  • 1（既定）: 発火するたびに毎回実行します。
  • 0: そのステートにいる間は最初の1回だけ実行します（ステートを離れて戻るとカウントはリセットされ、再び1回実行可能になります）。
  • N（2以上）: 発火したN回に1回だけ実行します。
    例：発火が毎フレーム続く（= 毎フレーム発火条件が真）なら、見かけ上はNフレームに1回の実行になります。発火が断続的な場合は、実行間隔も断続的になります（“フレーム”ではなく“発火回数”で数えるため）。

値に指定できるのは整数定数のみです（var/fvar/sysvar を含む式は不可）。

注意: 一部の解析記事では、エンジン内部でステート内のステートコントローラーごとに「Persistent用のカウンタ」が確保され、最大512個相当まで管理される、と説明されています。極端に大量のステートコントローラーを1つのステートに詰め込む設計は、可読性だけでなく実装上の制約にも触れやすいため、常時処理が肥大化している場合は分割・整理を推奨します。

仕様・バグ・エラー・変更点

  • mugen 1.0より前
    Addの値をマイナスに設定すると画面の色は変更されずにデバッグテキストの文字色が変化。文字色は、マイナスで指定した値の補色に変わります。ただし、赤の値をマイナスに指定した場合、文字色は変更されますが画面が暗くなってしまいます。
  • -
    AllPalFXの持続時間中に、呼び出されたOwnPal=1のExplodなどに効果はおよびません。
  • -
    PalFXを実行したキャラは効果の影響を受けません。
  • -
    SuperPauseによる暗転を行うと背景や相手への効果がなくなります。
  • -
    全く同じ数値のAdd、Mulを設定したAllPalFXを実行した場合、持続扱いとなり上記の効果が消える不具合を回避できません。違う値に設定した場合回避可能。
  • -
    Colorで0以下の値が設定可能ですが、警告文が表示され色の表示がおかしくなります。
  • -
    InvertAllはAdd,Sub,Mulなどで処理をしていると正しく機能しません。

  • 警告文

Q＆A(よくある質問)

表示される色の処理順

==========各条件を以下のように定義する。==========
基本色:
Add = Add_赤色(AR), Add_緑色(AG), Add_青色(AB)
SinAdd = Sin_赤色(SR), Sin_緑色(SG), Sin_青色(SB), 周期(P)

合成色:
Mul = Mul_赤色(MR), Mul_緑色(MG), Mul_青色(MB)

経過時間:(T) ※単位はフレーム、1秒=60フレーム
円周率:(Pi)

変更する色:
Palette_赤色(PR), Palette_緑色(PG), Palette_青色(PB)

==========処理の流れ==========
処理する色 = Palette_赤色(PR), Palette_緑色(PG), Palette_青色(PB)
↓
彩度(Color)
彩度を調整した色 = Color_赤色(CR), Color_緑色(CG), Color_青色(CB)
↓
経過時間(T)に表示される色は
赤要素(RR) = (CR + AR + SR * Sin(2*Pi*T/P)) * MR/256
緑要素(RG) = (CG + AG + SG * Sin(2*Pi*T/P)) * MG/256
青要素(RB) = (CB + AB + SB * Sin(2*Pi*T/P)) * MB/256
↓
色反転(InvertAll)
反転した赤要素(IR) = 256-RR
反転した緑要素(IG) = 256-RG
反転した青要素(IB) = 256-RB
↓
結果色(IR, IG, IB)が表示されます。
