ID

キャラクター情報 > プレイヤー/ヘルパーの一意ID取得 | 実装されたバージョン: 2002.04.14
引数 使用例 引用記事
プレイヤーのIDを返します。
このIDは、helperを含むプレイヤーが発生すると、自動で割り付けられ、その試合中は変更できません。自分で指定することもできません。
"playerID"リダイレクトキーワードに使用するため、敵のIDを取得するのが主な使用方法です。
戻り値の型: int

構文

  • ID

引数

なし

コードサンプル

プレイヤーのID番号をvalueに代入します。

  • value = ID

プレイヤーに最も近い敵のID番号をvalueに代入します。

  • value = EnemyNear, ID
