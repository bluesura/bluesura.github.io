P4Name

キャラクター情報 > 4P（2番目の敵）Nameの判定 | 実装されたバージョン: 2002.04.14 | 対象: 評価対象（既定: 実行者自身）
引数 使用例 引用記事

P4Name は、P4（2番目の敵）が存在する場合に、その .def 内部名 name を指定文字列と比較し、一致すれば 1、一致しなければ 0 を返します。

本トリガーは「比較式として使うトリガー」であり、単体で値を返す形式ではなく、= / != の比較としてのみ記述できます。

P4 が存在しない場合は bottom を返します。この場合、比較式は bottom となり成立しません。必要に応じて NumEnemy などで事前に存在チェックを行ってください。

関連するトリガー： NumEnemy , Name , P1Name , P2Name , P3Name

構文

  • P4Name = "名前"
  • P4Name != "名前"

引数

なし

コードサンプル

2番目の敵が特定の内部名なら専用分岐

P4 が存在する場合のみ比較し、条件一致でステート 9100 に移行します。

  • [State -2, SecondEnemySpecific]
  • Type = ChangeState
  • TriggerAll = NumEnemy >= 2
  • Trigger1 = P4Name = "Boss"
  • Value = 9100
