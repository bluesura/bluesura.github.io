TimeMod

時間 > ステート経過時間の剰余計算と比較 | 実装されたバージョン: 2002.04.14
引数 仕様・注意点 使用例 引用記事
Timeの剰余計算を比較した結果を返します。
ステート時間を第1指定値で割った余りが第2指定値と符号の条件を満たしている場合は1、満たしていない場合は0を返します。
%も割り算の余りを返す符号なので、代用可能で、このトリガーは使う必要がありません。

構文

  • TimeMod = 除数・正の整数, 剰余・整数
  • TimeMod != 除数・正の整数, 剰余・整数
  • TimeMod < 除数・正の整数, 剰余・整数
  • TimeMod > 除数・正の整数, 剰余・整数
  • TimeMod <= 除数・正の整数, 剰余・整数
  • TimeMod >= 除数・正の整数, 剰余・整数

引数

なし

仕様・バグ・エラー・変更点

  • エラー
    除数を0にするとSFalseを返します。

コードサンプル

ステートの経過時間が 3, 7, 11, 15, ...のときのトリガー

  • Trigger1 = TimeMod = 4, 3
