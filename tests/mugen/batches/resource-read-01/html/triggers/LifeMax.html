LifeMax

ライフ > 最大ライフの取得 | 実装されたバージョン: 2002.04.14 | 対象: ステート実行者
引数 仕様・注意点 使用例 引用記事

ステート実行者が持てる最大ライフ値を整数で返します。

通常はキャラクター定義の [Data] / life（Const(Data.Life)）に基づきますが、チームモードなど状況によっては補正されることがあります。

リダイレクト（例: Enemy,LifeMax）を付けた場合は、その評価対象の最大ライフを返します。

関連するステートコントローラー： LifeAdd , LifeSet , TargetLifeAdd
関連するトリガー： Life , Const

構文

  • LifeMax

引数

なし

仕様・バグ・エラー・変更点

  • Ikemen GO (Nightly, 2025-12-12 報告)

    LifeSet/LifeAdd と TargetLifeAdd の実行優先度が、MUGEN 1.1 と異なる可能性が報告されています。LifeMax を用いたライフ固定・復帰（例: LifeSet value = LifeMax）を行う設計では、互換性確認を推奨します。

コードサンプル

現在ライフが最大値の1/4未満のときの判定

  • Trigger1 = Life < LifeMax / 4

メディスン・メランコリー（相手側変数参照）を用いた周期ダメージ例

相手の変数を参照し、最大ライフ比率で周期的にダメージ量を組み立てる例です。最大ライフに連動させることで、ライフ設定が異なる環境でもスケールします。

  • [State -2]
  • Type = LifeAdd
  • TriggerAll = Enemy,Name="Medicine Melancholy"
  • Trigger1 = GameTime%8 =0
  • value = -Ceil(LifeMax/1000)*(Enemy,var(55))-Ceil(LifeMax/1000)*(Enemy,var(57))
  • Kill = 0
  • Absolute = 1

コンボ連携数の条件として使う（処理頻度を変化）

最大ライフと現在ライフの差分を用い、処理頻度（Persistent）の値を変化させる例です。

  • [State 000];中弾ばらまき（奥
  • Type = Explod
  • Trigger1 = fvar(0) = 0.7
  • Trigger1 = Time >= 80
  • Anim = 13047
  • PosType = P1
  • Pos = -40+(Random%60),90-(Random%240)
  • Scale = 0.6,0.6
  • Ownpal = 1
  • Vel = 0.1*(20+(Random%30))*Cos((-60+Random%120)*PI/180),0.1*(-40+(Random%80))*Sin((-60+Random%120)*PI/180)
  • SprPriority = 0
  • IgnoreHitPause = 1
  • Persistent = 45 - Floor((Root,LifeMax-Root,Life)/50)

ライフを最大ライフ比率で固定減少させる

最大ライフの 1/1000 を、2フレームに1回減算する例です（最大ライフが大きいほど減少量も増えます）。

  • [StateDef -2]
  • [State ];ライフ自動減少
  • Type = LifeAdd ;ライフ増減
  • value = -Ceil(LifeMax/1000) ;最大の1000分の1
  • Trigger1 = GameTime % 2 = 0 ;2フレームに1回（最大ライフ1000で約2000フレーム）
  • Trigger1 = RoundState = 2 ;試合中
  • IgnoreHitPause = 1 ;ヒットポーズ無視

ライフを半分にする（ラウンド開始前）

ラウンド開始前（試合前・暗転中）に現在ライフを最大値の半分へ設定する例です。

  • [StateDef -2]
  • [State ];ライフセット
  • Type = LifeSet ;ライフ指定
  • Value = Floor(LifeMax/2) ;体力半分
  • Trigger1 = RoundState = 0 ;試合前・暗転中

体力を8割にする（ラウンド開始前）

ラウンド開始前に現在ライフを最大値の8割へ設定する例です。

  • [StateDef -2]
  • [State ];ライフセット
  • Type = LifeSet ;ライフ指定
  • Value = Floor(LifeMax*0.8) ;体力八割
  • Trigger1 = RoundState = 0 ;試合前・暗転中
  • ;*1=100% *0.5=50% のように指定可能。Valueを特定数値にしても可。
  • ;※最大値より増やすことはできません。

根性補正の条件分岐（最大ライフ比率で分岐）

現在ライフ/最大ライフ比率を用いて補正値を分岐する例です。

  • [State ];根性補正 敷居40最大補正35
  • Type = VarSet
  • Trigger1 = !IsHelper
  • fvar(19) =
  • IfElse((Life*1000/(LifeMax)<=400),IfElse(Helper(60000),var(19)=0,(1-0.35)+(0.35*Life/(LifeMax*0.40)),1),1)
  • IgnoreHitPause = 1
  • Persistent = 1
