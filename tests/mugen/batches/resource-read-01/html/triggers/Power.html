Power

パワーゲージ > 現在パワーゲージ量の取得 | 実装されたバージョン: 2002.04.14 | 対象: 実行者自身
引数 使用例 引用記事

実行者の標準パワーゲージ（Power）の現在量を整数で返します。

通常は 0〜PowerMax の範囲で運用され、比較や分岐では上限を固定値にせず PowerMax 側も参照するのが安全です。

戻り値: int

関連するステートコントローラー： PowerAdd , PowerSet
関連するトリガー： PowerMax , Const

構文

  • Power

引数

なし

Q＆A(よくある質問)

最大値を固定値（例: 3000）で扱ってよい？

上限は PowerMax（通常は [Data] の power 定数）で取得できるため、固定値比較ではなく PowerMax を併用して条件を書くのが安全です。

コードサンプル

ゲージ残量が1,000（Lv1相当の例）以上のときの条件

ゲージを「1000刻み」で運用している想定の単純な比較例です。

  • Trigger1 = Power >= 1000

技の発動条件にする（ゲージが上限未満のときのみ）

コマンド入力と状態条件に加えて、ゲージ量で分岐する例です。

  • [State -1, Power Gathering]
  • Type = ChangeState
  • Value = 300
  • TriggerAll = Command = "A"
  • TriggerAll = Command != "HoldDown"
  • TriggerAll = StateType = S
  • TriggerAll = Power < 3000
  • Trigger1 = Ctrl

必要ゲージ量を条件分岐する（PalNoで閾値を切り替える例）

パレット番号等で必要ゲージ量（消費条件）を変える例です。

  • [State -1, Kung Fu Whip_Ex]
  • Type = ChangeState
  • Value = 1440
  • TriggerAll = var(59) = 0 || var(59) <= -2
  • TriggerAll = Command = "baem_ex"
  • TriggerAll = Power >= IfElse(PalNo > 6, 300, 500)
  • Trigger1 = StateType != A && (Ctrl || var(41) = 1)

ガードリカバリーをゲージ条件で発動（HitPause中も拾う例）

IgnoreHitPause = 1 を併用し、HitPause中でも成立させたい入力を拾う構成例です。

  • [State -1, Guard Recovery]
  • Type = ChangeState
  • TriggerAll = var(59) = 0 || var(59) <= -2
  • TriggerAll = Command = "Recovery"
  • Trigger1 = Power >= 500 && (StateNo = [150, 153])
  • Value = IfElse(Command = "HoldBack", 161, 166)
  • IgnoreHitPause = 1

AI行動条件にPowerを組み込む（複合条件の例）

距離・相手状態・乱数・ゲージ量などを併用してAI行動を分岐する例です。

  • [State -3]
  • Type = ChangeState
  • TriggerAll = var(59)
  • TriggerAll = RoundState = 2
  • TriggerAll = StateType != A
  • TriggerAll = P2Life > 0
  • TriggerAll = (P2StateType = S) || (P2StateType = C)
  • TriggerAll = Random <= var(59) * 5 * 80
  • TriggerAll = P2BodyDist X >= 0
  • TriggerAll = IsHelper(1111)
  • Trigger1 = P2MoveType != A
  • Trigger1 = Power >= 1333
  • Trigger1 = Random <= var(59) * 8
  • Trigger1 = P2BodyDist X = [55, 75]
  • Trigger1 = P2StateNo != 130 && P2StateNo != 131
  • Trigger1 = Ctrl
  • Trigger2 = StateNo = 210 && MoveHit && P2BodyDist X > 30 && Power >= 340
  • Trigger3 = StateNo = 240 && MoveHit && P2BodyDist X > 30 && Power >= 340
  • Trigger4 = StateNo = 410 && MoveHit && P2BodyDist X > 30 && Power >= 340 && AnimElemTime(4) > 0 && AnimTime <= 0
  • Value = 1020

必殺技の発動条件にする（ゲージ2,000以上など）

ゲージ条件と複数の成立条件（Ctrl / 被弾属性 / 接触）を併用する例です。

  • [State -1]
  • Type = ChangeState
  • Value = 6060
  • TriggerAll = var(59) = [0, 1]
  • TriggerAll = Command = "ulu"
  • TriggerAll = Power >= 2000
  • TriggerAll = StateType != A
  • TriggerAll = StateNo != 6470
  • TriggerAll = StateNo != 6471
  • TriggerAll = StateNo != 6600
  • Trigger1 = Ctrl
  • Trigger2 = HitDefAttr = SC, NA, SA, HA
  • Trigger3 = MoveContact = 1
