Lose

試合情報 > ラウンド敗北判定 | 実装されたバージョン: 2002.04.14 | 対象: プレイヤー自身
引数 使用例 引用記事

Lose は、ラウンドに敗北した場合に 1 を返します（KO・時間切れ・その他の敗北条件を含む／チーム戦ではチーム単位）。

敗北条件の内訳が必要な場合は LoseKO / LoseTime を併用します。引き分けは DrawGame で判定します。

敗北直後の処理は通常 RoundState = 3 以降で評価します。

関連するトリガー： LoseKO , LoseTime , Win , WinKO , WinPerfect , WinTime , DrawGame , MatchOver

  • Lose

引数

なし

コードサンプル

ラウンド敗北を1回だけ捕捉してフラグ化

ラウンド終了処理（RoundState = 3）で Lose を検出し、次ラウンド開始（RoundState = 0）でリセットします。

  • [State -2, LoseFlagSet]
  • Type = VarSet
  • Trigger1 = RoundState = 3 && Lose
  • Persistent = 0
  • V = 12
  • Value = 1

フラグのリセット

次ラウンド開始でフラグを落とします。

  • [State -2, LoseFlagClear]
  • Type = VarSet
  • Trigger1 = RoundState = 0
  • V = 12
  • Value = 0
