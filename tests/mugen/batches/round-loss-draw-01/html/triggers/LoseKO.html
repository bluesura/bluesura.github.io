LoseKO

試合情報 > KO敗北判定 | 実装されたバージョン: 2002.04.14 | 対象: プレイヤー自身
引数 使用例 引用記事

LoseKO は、ラウンドを「KO（自分の Life が 0 になって決着）」で敗北した場合に 1 を返します（チーム戦ではチーム単位）。

敗北直後の処理は通常 RoundState = 3 以降で評価します。

関連するトリガー： Lose , LoseTime , Win , WinKO , WinPerfect , WinTime , DrawGame , MatchOver

構文

  • LoseKO

引数

なし

コードサンプル

KO敗北を1回だけ捕捉してフラグ化

ラウンド終了処理（RoundState = 3）で LoseKO を1回だけ捕捉します。

  • [State -2, LoseKOFlagSet]
  • Type = VarSet
  • Trigger1 = RoundState = 3 && LoseKO
  • Persistent = 0
  • V = 10
  • Value = 1

フラグのリセット

次ラウンド開始でフラグを落とします。

  • [State -2, LoseKOFlagClear]
  • Type = VarSet
  • Trigger1 = RoundState = 0
  • V = 10
  • Value = 0
