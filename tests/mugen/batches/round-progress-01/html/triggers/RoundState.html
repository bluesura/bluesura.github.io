RoundState

試合情報 > ラウンド進行状態の取得 | 実装されたバージョン: 2002.04.14 | 対象: 全プレイヤー共通
引数 仕様・注意点 使用例 引用記事

RoundStateは、現在のラウンド進行状態を整数で返します（同一試合内では全プレイヤーで同じ値になります）。

  • 0: Pre-intro（画面フェードイン）
  • 1: Intro（イントロ演出）
  • 2: Fight（試合本編）
  • 3: Pre-over（決着直後〜勝敗表示前）
  • 4: Over（勝敗表示・勝利ポーズなど）

ステート遷移との関係

  • RoundStateは「ラウンド全体の状態」であり、各キャラクターのStateNoとは独立です。つまり、キャラがどのStateDefに居ても、RoundStateは試合進行に合わせて変化します。
  • MUGENは毎フレーム、特殊ステート-3→-2→-1→現在ステートの順で上から評価します。ラウンド進行に合わせて常時監視したい処理は、-3/-2に置くのが基本です。
  • 標準のcommon1.cnsでは、ラウンド開始時にStatedef 5900（Initialize）が実行され、1Rのみ190（Pre-intro）→191（Intro）へ遷移する例が示されています（以降のラウンドはそのまま0（立ち動作）へ遷移）。
  • ヘルパーは通常-3/-2を持たないため、ラウンド進行の監視をヘルパー側に置く設計は避け、root（本体）側で行うのが安全です。

仕様・バグ・エラー・変更点

  • Ikemen GO Nightly (2025-08-09以降)

    「Fight!」表示中（プレイヤーがまだ操作不能な区間）にRoundStateが2を返してしまう挙動を避け、RoundStateが1を返すよう調整されています（MUGEN互換実装上の差分）。

Q＆A(よくある質問)

RoundState = 2 なのに操作できない（フライングできない）ことがある

MUGENでは「Fight!」表示中など、プレイヤーがまだCtrl = 0の区間でもRoundState = 2になり得ます。RoundState = 2に加えてCtrlや自前の「入力解禁フラグ」を併用してください。

ラウンド開始（RoundStateが2に入った瞬間）を1フレームだけ検出したい

前フレームのRoundStateを変数に保存し、prev != 2 && now = 2で遷移を検出します。監視は毎フレーム走るStatedef -3/-2に置くのが基本です。

コードサンプル

フライング防止（RoundState=2 かつ Ctrl で入力解禁）

RoundStateが2でも操作不能な区間を考慮し、Ctrlが立ったタイミングで自前フラグを立てて技発動条件に組み込みます。

  • ; -3: ラウンド本編以外では常にロック
  • [State -3, StartFlagReset]
  • type = VarSet
  • trigger1 = RoundState != 2
  • var(45) = 0
  • IgnoreHitPause = 1
  • ; ---
  • ; -3: 本編中にCtrlが立ったら入力解禁
  • [State -3, StartFlagSet]
  • type = VarSet
  • triggerall = RoundState = 2
  • trigger1 = Ctrl
  • var(45) = 1
  • IgnoreHitPause = 1
  • ; ---
  • ; -1: 例）コマンド技の発動を解禁フラグで制御
  • [State -1, ExampleMove]
  • type = ChangeState
  • triggerall = var(45)
  • triggerall = Ctrl
  • trigger1 = command = "x"
  • value = 1000
