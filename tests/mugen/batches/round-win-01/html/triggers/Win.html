Win

試合情報 > ラウンド勝利判定 | 実装されたバージョン: 2002.04.14 | 対象: プレイヤー自身
引数 仕様・注意点 使用例 引用記事

Win は、ラウンドに勝利した場合に 1 を返します（KO・時間切れ・その他の勝利条件を含む／チーム戦ではチーム単位）。

勝利条件の内訳が必要な場合は WinKO / WinTime / WinPerfect を併用します。

勝敗確定のフレーム帯は通常 RoundState = 3（ラウンド終了処理）以降です。ラウンド勝利直後の処理は RoundState と組み合わせて行うのが安全です。

関連するトリガー： WinKO , WinPerfect , WinTime , Lose , LoseKO , LoseTime , DrawGame , MatchOver

仕様・バグ・エラー・変更点

  • MatchOver の遅延

    MatchOver は最短でも win pose のステート（例: Statedef 180）に到達するまで 1 になりません。ラウンド単位の勝敗は Win、マッチ決着は MatchOver と使い分けます。

  • 運用上の注意

    勝利演出へ強制的に ChangeState する場合、RoundState = 4 や Win だけを条件にすると標準の win pose 遷移を阻害するケースがあるため、RoundState = 3 での分岐が推奨されます。

コードサンプル

ラウンド勝利を1回だけ捕捉してフラグ化

ラウンド終了処理（RoundState = 3）で Win を検出し、次ラウンド開始（RoundState = 0）でリセットします。

  • [State -2, WinFlagSet]
  • Type = VarSet
  • Trigger1 = RoundState = 3 && Win
  • Persistent = 0
  • V = 3
  • Value = 1

フラグのリセット

次ラウンド開始でフラグを落とします。

  • [State -2, WinFlagClear]
  • Type = VarSet
  • Trigger1 = RoundState = 0
  • V = 3
  • Value = 0
