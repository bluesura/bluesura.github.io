WinKO

試合情報 > KO勝利判定 | 実装されたバージョン: 2002.04.14 | 対象: プレイヤー自身
引数 仕様・注意点 使用例 引用記事

WinKO は、ラウンドを「KO（相手の Life が 0 になって決着）」で勝利した場合に 1 を返します（チーム戦ではチーム単位）。

勝敗確定のフレーム帯は通常 RoundState = 3（ラウンド終了処理）以降です。ラウンド勝利直後の処理は RoundState と組み合わせて行うのが安全です。

関連するトリガー： Win , WinPerfect , WinTime , Lose , LoseKO , LoseTime , DrawGame , MatchOver

仕様・バグ・エラー・変更点

  • 運用上の注意

    勝利演出へ強制的に ChangeState する場合、RoundState = 4 や Win だけを条件にすると、標準の win pose（Statedef 180）遷移を阻害するケースがあるため、RoundState = 3 での分岐が推奨されます。

コードサンプル

KO勝利を1回だけ捕捉してフラグ化

ラウンド終了処理（RoundState = 3）で WinKO を検出し、次ラウンド開始（RoundState = 0）でリセットします。

  • [State -2, WinKOFlagSet]
  • Type = VarSet
  • Trigger1 = RoundState = 3 && WinKO
  • Persistent = 0
  • V = 0
  • Value = 1

フラグのリセット

次ラウンド開始でフラグを落とします。

  • [State -2, WinKOFlagClear]
  • Type = VarSet
  • Trigger1 = RoundState = 0
  • V = 0
  • Value = 0
