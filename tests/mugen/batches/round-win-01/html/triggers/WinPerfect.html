WinPerfect

試合情報 > パーフェクト勝利判定 | 実装されたバージョン: 2002.04.14 | 対象: プレイヤー自身
引数 使用例 引用記事

WinPerfect は、ラウンドを「無傷（no life lost）」で勝利した場合に 1 を返します（チーム戦ではチーム単位）。

勝敗確定のフレーム帯は通常 RoundState = 3 以降です。パーフェクト専用の演出分岐は RoundState と組み合わせて行うのが安全です。

なし

Q＆A(よくある質問)

Lifeが最大値ならWinPerfectと同じですか？

公式定義は「無傷（no life lost）」です。Life が途中で減ったかどうかの履歴を含むため、Life = LifeMax だけでは同一判定になりません。見た目上の“最大まで回復”をパーフェクト扱いにしたい場合は、独自フラグで別判定を用意してください。

コードサンプル

パーフェクト勝利で専用フラグを立てる

ラウンド終了処理（RoundState = 3）で WinPerfect を捕捉します。

  • [State -2, PerfectWinFlagSet]
  • Type = VarSet
  • Trigger1 = RoundState = 3 && WinPerfect
  • Persistent = 0
  • V = 1
  • Value = 1

フラグのリセット

次ラウンド開始でフラグを落とします。

  • [State -2, PerfectWinFlagClear]
  • Type = VarSet
  • Trigger1 = RoundState = 0
  • V = 1
  • Value = 0
