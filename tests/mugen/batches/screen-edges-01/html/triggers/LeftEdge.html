LeftEdge

座標 > 画面左端（screen edge）のX座標（ステージ座標系） | 実装されたバージョン: 1.1 | 対象: 実行者自身
引数 仕様・注意点 使用例 引用記事

LeftEdge は、画面左端（screen edge）の X座標 を、絶対ステージ座標をfloatとして返します。

向き（Facing）には依存しません。左端の画面端座標が必要な場合にそのまま利用できます。

関連するステートコントローラー： ScreenBound
関連するトリガー： RightEdge , TopEdge , BottomEdge , FrontEdge , BackEdge , CameraPosX , CameraZoom , GameWidth , ScreenWidth

構文

  • LeftEdge

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.1

    LeftEdge は、RightEdge/TopEdge/BottomEdge と同様に、MUGEN 1.1 系で追加された「画面端座標トリガー」です。

  • 注意

    ここでの「画面端」は現在のカメラ表示範囲の端（screen edge）です。ステージ境界（stage boundary）そのものとは限りません。

  • 注意

    CameraPos / GameWidth と同様に、値は「実行者のローカル座標系（localcoord）」側の単位として扱われます。ズーム（CameraZoom）等で GameWidth が変化すると LeftEdge も連動して変化します。

Q＆A(よくある質問)

BackEdge との違いは？

LeftEdge は常に「画面左端」のX座標を返します。

BackEdge は実行者の向き（Facing）に応じて、背面側の画面端（右向きなら左端、左向きなら右端）のX座標を返します。

コードサンプル

等価式：LeftEdge の概念式

LeftEdge は概念的には CameraPos X - GameWidth / 2 と等価です。

  • ; LeftEdge 等価式
  • CameraPos X - GameWidth / 2

距離の取り方：左端まで何pxか（向き非依存）

「左端まで何pxか」を向き非依存で扱うなら、座標差分を距離として使えます（距離トリガーではなく座標の差分）。

  • ; 左端までの距離（向き非依存の差分例）
  • FVar(0) = Abs((Pos X + CameraPos X) - LeftEdge)

公式例：画面左端より左にいるか判定する

実行者のステージ座標（Pos X + CameraPos X）と、画面左端座標（LeftEdge）を直接比較します。

  • ; 画面左端より左にいるか
  • Trigger1 = Pos X + CameraPos X < LeftEdge

RightEdge と LeftEdge から「見えている横幅」を求める

画面左右端の差分は、現在のゲーム空間幅（概ね GameWidth 相当）になります。ズーム等で値が変動する挙動の確認にも使えます。

  • FVar(0) = RightEdge - LeftEdge

画面左端から一定距離外に出たら削除する（Helper/Projectile運用例）

画面外へ出たオブジェクトを安全に後始末したい場合の例です（余裕を持たせて-60px）。

  • Trigger1 = Pos X + CameraPos X < LeftEdge - 60
