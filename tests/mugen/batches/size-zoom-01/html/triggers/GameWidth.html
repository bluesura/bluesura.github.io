GameWidth

システム情報 > ゲーム表示領域（ゲーム空間）の幅取得 | 実装されたバージョン: 2009.10.25
引数 仕様・注意点 使用例 引用記事

現在の「ゲーム空間（カメラ表示範囲）」の横幅を、プレイヤーのローカル座標系で実数として返します。

ズーム倍率が変化する環境では値がズーム倍率に反比例して変動します（例：ズーム0.5ならGameWidthはズーム1.0時の2倍）。

関連するトリガー： GameHeight , ScreenWidth , ScreenPosX , ScreenPosY , LeftEdge , RightEdge

Q＆A(よくある質問)

ScreenWidthとの違いは？

GameWidthは「ゲーム空間（カメラ表示範囲）」の幅で、ズームの影響を受けます。ScreenWidthは「スクリーン空間」の幅で、ズームの影響を受けません。

キャラによって戻り値が変わることがある？

あります。戻り値は「プレイヤーのローカル座標系」で返るため、キャラ側のローカル座標（スケーリング設定）が異なると、同じ見た目でも数値がスケールして返ります。比較・閾値判定では、同一基準のローカル座標で統一するのが安全です。

コードサンプル

画面中央より右側にいるか判定（ズーム対応）

ScreenPosと組み合わせて、画面中心を境に左右判定します。

  • [State -2, IsRightOfCenter]
  • Type = VarSet
  • Trigger1 = 1
  • Var(0) = (ScreenPos X >= GameWidth / 2)

画面左端から一定距離以内にいるか判定（ズーム対応）

「ゲーム空間」基準で左端寄りかを判定します。

  • [State -2, IsNearLeftEdge]
  • Type = VarSet
  • Trigger1 = 1
  • ; 左端から80未満（プレイヤーローカル座標系）
  • Var(1) = (ScreenPos X < 80)
