ScreenHeight

システム情報 > ゲーム画面の高さ取得 | 実装されたバージョン: 1.1
引数 仕様・注意点 使用例 引用記事

画面座標（screen space）の縦サイズを、ピクセル単位の実数で返します。

カメラのズーム倍率の影響を受けません（ズームで変化するのは GameHeight 側）。

主に Explod の space = screen など、画面固定演出のレイアウト計算に使います。

関連するトリガー： ScreenWidth , GameHeight , GameWidth

構文

  • ScreenHeight

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.1

    ステージズーム導入に伴い、画面座標（screen space）向けとして ScreenWidth/ScreenHeight が追加された。

Q＆A(よくある質問)

GameHeight / GameWidth と何が違う？

ScreenHeight/ScreenWidth は「画面座標（screen space）」の寸法で、カメラ移動・ズームの影響を受けません。

GameHeight/GameWidth はズーム倍率に応じて変化し、画面上で見えるステージ範囲（ステージ座標）を表します。

IKEMEN GO では互換設定（mugenVersion）により、GameWidth/GameHeight を 1.0 相当として扱い、結果的に ScreenWidth/ScreenHeight と同等にする挙動があります。

コードサンプル

画面サイズをデバッグ表示する

現在の画面座標（screen space）の解像度を表示して確認します。

  • [State -2, DebugScreenSize]
  • type = DisplayToClipboard
  • trigger1 = 1
  • text = "Screen: %d x %d", ScreenWidth, ScreenHeight

画面中央に固定した Explod を出す

space = screen を使うと、ステージ移動やズームに追従しない画面固定演出になります。

  • [State 0, ScreenCenterExplod]
  • type = Explod
  • trigger1 = !Time
  • anim = 9000
  • id = 9000
  • space = screen
  • pos = ScreenWidth/2, ScreenHeight/2
  • bindID = -2
