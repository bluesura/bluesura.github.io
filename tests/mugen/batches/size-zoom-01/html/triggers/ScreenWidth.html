ScreenWidth

システム情報 > ゲーム画面の幅取得 | 実装されたバージョン: 1.1
引数 仕様・注意点 使用例 引用記事

画面座標（screen space）の横サイズを、ピクセル単位の実数で返します。

カメラのズーム倍率の影響を受けません（ズームで変化するのは GameWidth 側）。

主に Explod の space = screen など、画面固定演出のレイアウト計算に使います。

関連するトリガー： ScreenHeight , GameWidth , GameHeight

構文

  • ScreenWidth

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.1

    ステージズーム導入に伴い、画面座標（screen space）向けとして ScreenWidth/ScreenHeight が追加された。

Q＆A(よくある質問)

GameWidth / GameHeight と何が違う？

ScreenWidth/ScreenHeight は「画面座標（screen space）」の寸法で、カメラ移動・ズームの影響を受けません。

GameWidth/GameHeight はズーム倍率に応じて変化し、画面上で見えるステージ範囲（ステージ座標）を表します。

IKEMEN GO では互換設定（mugenVersion）により、GameWidth/GameHeight を 1.0 相当として扱い、結果的に ScreenWidth/ScreenHeight と同等にする挙動があります。

コードサンプル

画面右上に固定した Explod を出す

右上固定の演出を置く例です（画面座標なのでステージ移動・ズームの影響を受けません）。

  • [State 0, ScreenTopRightExplod]
  • type = Explod
  • trigger1 = !Time
  • anim = 9001
  • id = 9001
  • space = screen
  • pos = ScreenWidth, 0
  • bindID = -2

画面幅を使って HUD 要素のX座標を計算する

画面端から一定距離（例: 16px）に配置したい場合の計算例です。

  • [State -2, HudExplod]
  • type = Explod
  • trigger1 = !Time
  • anim = 9010
  • id = 9010
  • space = screen
  • pos = ScreenWidth - 16, 16
  • bindID = -2
