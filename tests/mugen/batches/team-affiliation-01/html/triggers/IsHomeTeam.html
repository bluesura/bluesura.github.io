IsHomeTeam

試合情報 > 自チームがホーム側かの判定 | 実装されたバージョン: 2002.04.14 | 対象: 実行者自身
引数 仕様・注意点 使用例 引用記事

IsHomeTeam は、このトリガーを評価しているプレイヤー（キャラクター）のチームが「ホームチーム」とみなされる場合に 1 を返します。該当しない場合は 0 を返します。

  • アーケード系モードでは、コンピュータ側チームが常にホームチームとして扱われます。
  • 対人対戦（Player vs Player）では、P1（左側）がホームチームとして扱われます。
関連するトリガー： TeamSide , TeamMode

構文

  • IsHomeTeam

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.0 / 1.1

    公式ドキュメント上の定義は、アーケード系モードではCPU側がホーム、対人対戦ではP1（左側）がホームという扱いです。

  • IKEMEN GO v0.99.0 / Nightly

    互換性の差分／不具合として、IsHomeTeam が常に 1 を返すという報告があります。IKEMEN GO を対象にする場合は、実機での挙動確認や、TeamSide 等による代替判定を併用してください。

Q＆A(よくある質問)

IsHomeTeam と TeamSide の違いは？

TeamSide は左右（P1側/ P2側）の区別に近い値を返します。一方 IsHomeTeam はモード依存で「ホーム扱い」を返すため、アーケード系モードではCPU側がホームになり得ます。左右判定が目的なら TeamSide を優先し、ホーム/アウェイ演出など「ホーム扱い」が目的なら IsHomeTeam を使い分けてください。

コードサンプル

ホーム/アウェイでイントロ演出を分岐する

ラウンド開始直後に、ホーム側とアウェイ側で別ステートへ分岐します（主に対人対戦向け）。

  • [State -2, IntroBranchByHomeTeam]
  • Type = ChangeState
  • Trigger1 = RoundState = 0
  • Trigger1 = Time = 0
  • Value = IfElse(IsHomeTeam, 9000, 9010)
