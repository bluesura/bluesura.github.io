TeamMode

キャラクターのパラメーター > 試合のチーム形式は何ですか？ | 実装されたバージョン: 2002.04.14 | 対象: ステート実行者自身
引数 仕様・注意点 使用例 引用記事

TeamMode は、現在のチーム形式を判定する比較式として使うトリガーです。比較式が成立すれば 1、成立しなければ 0 を返します。

モードは Single / Simul / Turns のいずれかとして扱われます（シングル戦 / 同時出場のタッグ戦 / 交代制のチーム戦）。

使用できる比較演算子は = と != のみです。

関連するトリガー： TeamSide , NumPartner , NumEnemy , IsHomeTeam

構文

  • TeamMode = Single
  • TeamMode != Single
  • TeamMode = Simul
  • TeamMode != Simul
  • TeamMode = Turns
  • TeamMode != Turns

引数

なし

仕様・バグ・エラー・変更点

  • MUGEN 1.0 RC4 (2009-10-25)

    TeamMode などに対する != 演算子の解析が不正になる不具合が修正されました。

  • MUGEN 1.0 RC5 (2009-10-28)

    TeamMode（および HitDefAttr）の評価が誤る不具合が修正されました。

  • IKEMEN GO

    追加チームモード Tag が存在し、TeamMode はこのモードを Tag として返します。あわせて、Ratio モードは Turns として扱われます。

Q＆A(よくある質問)

サバイバル時の注意点はありますか？

公式仕様では、サバイバル時に「敵側」は Turns として扱われます。TeamMode を敵側へリダイレクトして判定する場合は、この挙動を前提に条件分岐してください。

IKEMEN GO の追加モードはどう扱われますか？

IKEMEN GO には Tag モードがあり、TeamMode はこのモードを Tag として返します。Ratio は Turns として扱われます。

コードサンプル

シングル戦の時だけ成立させる

シングル戦（1 vs 1）でのみ処理を有効化したい場合の基本形です。

  • [State -2, SingleOnly]
  • Type = Null
  • Trigger1 = TeamMode = Single

Simul（同時出場のタッグ戦）でのみ成立させる

タッグ戦（同時出場）向けの分岐例です。

  • [State -2, SimulOnly]
  • Type = Null
  • Trigger1 = TeamMode = Simul

Turns（交代制チーム戦）でのみ成立させる

交代制のチーム戦（Turns）向けの分岐例です。

  • [State -2, TurnsOnly]
  • Type = Null
  • Trigger1 = TeamMode = Turns
